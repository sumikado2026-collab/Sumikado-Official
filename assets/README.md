# 網站素材 / Website Assets

此資料夾只存放已核准、會隨測試預覽部署，並在未來供正式網站使用的素材。

This folder contains only approved assets that deploy with the staging preview and will be used by the future production website.

- `brand/` — 商標與品牌素材 / logos and brand assets
- `people/` — 人物與創辦人照片 / people and founder photos
- `products/` — 產品包裝與產品視覺 / product packaging and visuals
- `kitchen/` — 廚房、活動與獎勵視覺 / kitchen, event, and reward visuals
- `recipes/` — 食譜照片 / recipe images

新的參考素材請先放在工作區的 `Resources/` 資料夾。確認要用於正式網站後，再將它加入適當的分類資料夾。

Place new reference materials in the workspace `Resources/` folder first. Move an asset into the appropriate category here only after it is approved for production use.
